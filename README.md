> This Magento 2 module disables any client-side service worker for the Magento Admin Panel

### Installation
Install this package via composer:
```bash
composer require yireo/magento2-disable-service-worker-in-admin
```

Next, enable this module:
```bash
bin/magento module:enable Yireo_DisableServiceWorkerInAdmin
```
